# Preço mínimo

O **preço mínimo** é o preço de equilíbrio (*break-even*): o ponto em que o
procedimento se paga, mas **sem gerar lucro nenhum**.

## Fórmula

```
preço mínimo = custo direto total ÷ (1 − cartão − imposto − comissão)
```

É a mesma fórmula do preço recomendado, **sem** a margem alvo no denominador:

```
preço mínimo    = custo direto ÷ (1 − descontos)
preço recomendado = custo direto ÷ (1 − descontos − margem alvo)
```

## O que ele cobre

O preço mínimo paga exatamente:

1. **custo direto total** — custo fixo alocado + material + laboratório +
   implantes + outros;
2. **cartão + imposto + comissão** — as fatias proporcionais ao preço.

...e nada mais: **não sobra lucro**.

## Exemplo

Custo direto de R$ 190 e descontos de 51,5%:

```
preço mínimo = 190 ÷ (1 − 0,515) = 190 ÷ 0,485 = R$ 391,75
```

Conferindo as fatias nesse preço:

| Destino | Valor |
|---------|-------|
| Cartão + imposto + comissão (51,5%) | R$ 201,75 |
| Custo direto | R$ 190,00 |
| **Sobra (lucro)** | **R$ 0,00** |

## Na prática

- **Cobrar abaixo do mínimo** → a clínica **perde dinheiro** (não cobre nem o
  custo direto + taxas).
- **Cobrar o mínimo** → empata; o procedimento se sustenta, mas não gera lucro.
- **Cobrar o recomendado** → é o mínimo + a margem alvo por cima.

Em resumo: o mínimo responde *"qual o menor preço para eu não sair no prejuízo"*.
