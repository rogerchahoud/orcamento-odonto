# Preço recomendado

O **preço recomendado** é o preço que, além de cobrir custo direto e taxas,
**embute a margem alvo** — o lucro desejado por procedimento.

## Fórmula

```
preço recomendado = custo direto total ÷ (1 − cartão − imposto − comissão − margem alvo)
```

## Relação com o preço mínimo

O recomendado é o [preço mínimo](preco-minimo.md) acrescido da margem:

```
preço mínimo    = custo direto ÷ (1 − descontos)
preço recomendado = custo direto ÷ (1 − descontos − margem alvo)
```

## A intuição: o preço é dividido em "fatias"

O preço recomendado é o valor `P` que cobre, proporcionalmente:

1. o **custo direto** (fixo alocado + variáveis) — fatia fixa;
2. **cartão + imposto + comissão** — fatias proporcionais ao preço;
3. **lucro** — a fatia da margem alvo.

Algebricamente:

```
P = custo direto + P×(descontos) + P×(margem)
```

que, rearranjado, dá a fórmula do topo. Por isso
`lucro = P × margem` é exatamente a sobra após pagar custo direto e descontos.

## Exemplo

Custo direto de R$ 190, descontos de 51,5% e margem alvo de 30%:

```
preço recomendado = 190 ÷ (1 − 0,515 − 0,30) = 190 ÷ 0,185 = R$ 1.027,03
```

Ver também: [lucro.md](lucro.md) para o cálculo do lucro a partir daqui.
